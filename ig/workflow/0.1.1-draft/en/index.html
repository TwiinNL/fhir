This implementation guide is the technical specification of TA Workflow 0.3 (draft), part of the technical core of the Twiin Afsprakenstelsel.

This guide contains the conformance artifacts of TA Workflow: the profiles of the Coordination Task, the Cancellation Request Task, the Authorization Cancellation Request Task, the ServiceRequest and the Subscription, the code system and value set of the TA, and the CapabilityStatement of the Placer's server. The requirements themselves are in the TA; the pages of this guide are informative. See Artifacts overview and Requirements not expressed in artifacts.

Status of this version

The normative status of a version of this implementation guide follows from the release of the Afsprakenstelsel that references it. A version is normative only as far as, and as long as, a release of the Afsprakenstelsel refers to it.
